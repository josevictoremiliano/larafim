# Política de privacidade · Privacy policy

*Última atualização / Last updated: 2026-11-24*

[Português](#português) · [English](#english)

## Português

O Larafim é um aplicativo de código aberto que roda só no seu computador. Ele **não coleta, não
guarda em servidores e não compartilha** dados pessoais.

**O que o Larafim não faz**

- Não tem conta, login nem cadastro.
- Não envia telemetria, estatísticas de uso, relatórios de erro nem dados dos seus projetos.
- Não usa anúncios nem rastreadores.

**Quando ele acessa a internet**

Só para baixar o que você pede, direto das fontes oficiais: PHP (php.net), Node.js (nodejs.org),
MariaDB (mariadb.org), Composer (getcomposer.org), Xdebug (xdebug.org) e ferramentas publicadas no
GitHub (github.com). Na versão instalada fora da Microsoft Store, ele também consulta o GitHub para
saber se há uma versão nova do Larafim e, quando você clica em *Atualizar e reiniciar*, baixa de lá o
instalador novo. A verificação pode ser desligada em
*Configurações › Sobre › Verificar automaticamente*. Nesses acessos, os servidores recebem apenas o
que qualquer download recebe (como o endereço IP), sob as políticas de privacidade de cada site.

**O que fica no seu computador**

Configurações, lista de projetos, logs e runtimes ficam em `%LOCALAPPDATA%\Larafim`. Senhas de bancos
de dados e chaves de storage ficam protegidas pelo Windows (DPAPI), só para o seu usuário. Nada disso
sai do seu computador.

**Contato**

Dúvidas: abra uma issue em <https://github.com/josevictoremiliano/larafim/issues>.

## English

Larafim is an open-source app that runs only on your computer. It **does not collect, store on
servers or share** personal data.

**What Larafim does not do**

- No account, sign-in or registration.
- No telemetry, usage statistics, crash reports or project data are sent anywhere.
- No ads and no trackers.

**When it connects to the internet**

Only to download what you ask for, straight from the official sources: PHP (php.net), Node.js
(nodejs.org), MariaDB (mariadb.org), Composer (getcomposer.org), Xdebug (xdebug.org) and tools
published on GitHub (github.com). When installed outside the Microsoft Store, it also checks GitHub
for a new Larafim release and, when you click *Update and restart*, downloads the new installer from
there. The check can be turned off in *Settings › About › Check automatically*.
These servers only receive what any download sends (such as your IP address), under each site's own
privacy policy.

**What stays on your computer**

Settings, the project list, logs and runtimes are kept in `%LOCALAPPDATA%\Larafim`. Database passwords
and storage keys are protected by Windows (DPAPI), for your user only. None of this leaves your
computer.

**Contact**

Questions: open an issue at <https://github.com/josevictoremiliano/larafim/issues>.
